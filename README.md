## ✨ Highlights / 概览

**English** — A command-line tool that corrects OCR errors in EPUB ebooks using Large Language Models. It preserves original formatting, supports batch and concurrent processing, deduplication and caching, and generates detailed correction reports.

**中文** — 一款基于大语言模型（LLM）的命令行工具，专用于纠正 EPUB 电子书中因 OCR 识别产生的错别字与生僻字问题。完整保留原排版格式，支持批量并发处理、去重缓存、预过滤，并生成详细的纠错报告。
